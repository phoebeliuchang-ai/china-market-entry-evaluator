# 中國市場進入評估

> 台灣品牌/產品進入中國跨境電商市場的專業評估技能（Coze Skill）

將「台灣產品清單」轉化為「中國跨境電商可執行的上架優先順序決策報告」。  
核心是回答：**哪些品先上、哪些暫緩、哪些絕對不能上、為什麼。**

## 🎯 這個技能能做什麼

| 能力 | 說明 |
|------|------|
| 星級上架評判 | 5 星級評判體系，每品有競品數據支撐，不憑感覺打分 |
| 天貓/京東競品搜索 | 真實平台在售數據，記錄品牌/店鋪/參考價/銷量 |
| 跨境合規預檢 | CITES 保護物種、藥典毒性中藥、正面清單、動物源成分逐品檢查 |
| 品類場景映射 | 按消費場景分組，輸出首批建議清單 |
| 定價策略建議 | 台幣→人民幣定價參考，含跨境成本結構 |
| 執行時序規劃 | 週次×動作，落地可執行 |

## 📦 產出物

| 產出 | 格式 | 說明 |
|------|------|------|
| 全品項評估總表 | `.xlsx` | 4 個 Sheet：全品項總表 / 首批建議 / 品類×首批對照 / 合規紅線 |
| 分析說明 | `.md` | 8 章節完整報告：全貌盤點→星級分布→首批建議→競品格局→合規預警→定價→時序→結論 |

## 🚀 如何在 Coze 中使用

### 方法一：從 Coze 商店安裝（推薦）
1. 進入 [Coze 技能商店](https://www.coze.cn)
2. 搜尋「中國市場進入評估」
3. 點擊「添加技能」加入你的 Bot 即可

### 方法二：本地導入
1. 將本 repo 下載或 clone 到本地
2. 將 `SKILL.md` 放入你的 Coze 工作區的 `.skills/skill_china-market-entry-evaluator/` 目錄
3. 在 Coze Bot 設定中啟用該技能

## 📐 核心方法論

### 5 星級上架評判體系

| 星級 | 判定條件 | 上架建議 |
|------|---------|---------|
| ⭐⭐⭐⭐⭐ | 有 1 萬+ 銷量競品驗證，市場充分教育 | 首批必上 |
| ⭐⭐⭐⭐ | 1,000-1 萬銷量競品，或無直接競品但品類認知度高 | 首批跟進 |
| ⭐⭐⭐ | 小眾品類或需教育市場，有需求但規模未驗證 | 選擇性上架 |
| ⭐⭐ | 品類極小眾，或含跨境合規敏感成分 | 暫緩/謹慎 |
| ⭐ | 成分踩紅線 / 無市場需求 / 跨境不可行 | 不建議 |

### 合規預檢重點
- CITES 保護物種（犀角、虎骨、穿山甲片等）
- 中國藥典毒性中藥（麻黃鹼、附子大劑量等）
- 跨境正面清單外藥品（口服中成藥不在正面清單內）
- 動物源成分（燕窩需查產地准入、鹿茸需查物種）
- 2026 年新法規變化追蹤

## ⚠️ 重要免責聲明

1. 本技能為輔助評估工具，**不構成法律、法規或商業建議**；最終上架決策請以最新法規與專業律師意見為準
2. 星級評判基於公開平台數據，可能存在時效性差異；實際合規狀態以平台審核為準
3. 跨境電商法規變動頻繁，建議定期對照最新正面清單與禁令
4. 本技能不對任何商業決策結果承擔責任
